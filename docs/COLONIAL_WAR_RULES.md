# 0.7殖民倾向、国内授权与战争

本版以 [DESIGN.md](DESIGN.md) 的国内谈判为核心。0.6的统一厌战、固定合法性与产业/人口效果已移除；旧规则仅在 [LEGACY_0_6_COLONIAL_RULES.md](LEGACY_0_6_COLONIAL_RULES.md) 供回溯。

| 殖民政策 | 扩张支持倾向 | 接纳支持倾向 |
|---|---:|---:|
| 无殖民事务 | 0 | 0 |
| 殖民迁居 | +15 | −10 |
| 殖民开发/剥削 | +20 | −20 |

平等主义、人权科技各提供一阶段，每阶段扩张−15、接纳+15；医疗和军事科技不计作人文阶段。这些是集团支持分的可调代理，不是基础通过率或居民态度的历史测量。取得土地和接纳居民分别计算；殖民法律不批量批准州，也不自动赋予居民权益。

0.7取消科技/殖民政策的通用行政成本倍率。接纳仍须为具体州支付年度行政预留，实际公民权与宗教法律才为可信权利理由提供支持。铁路、海军基地的勘察与建设义务另计。

各国可浏览合格外国目标，远方目标需要原版区域利益；不再另等6/12月重点成熟。目标消失或不再合格时取消审议或显示明确提示。

国内授权仍记录所选目标的批准，尚在审议不算批准；一州接纳不覆盖另一州，真实宣称按原版州区域记录。**不禁用原版外交按钮、不使用额外战争厌战或战争回调加罚。** 防御、收复、未授权扩张和正常授权战争都继续承担原版外交与损耗。旧战争诊断接口仅供兼容，不产生玩法奖励或惩罚。

157项离线测试通过；它们以明确地理、人口和政治数据夹具执行实际脚本，JSON恢复不是实际游戏存档模拟。1.13本体未提供，仍须确认界面、国库扣款、行政预留、实际建筑计数及目标在转手/部分州变化后的持久性。
