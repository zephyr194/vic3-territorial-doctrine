# 0.9殖民利益、接纳与国内战争计划

殖民政策仍区分取得土地和接纳居民，分别作为机会/负担的背景输入：无殖民事务0/0，迁居+15/-10，开发+20/-20。**它们不再直接乘一个统一正权重加给八个集团。** 现行各集团权重与人文响应见 [DESIGN.md](DESIGN.md) 的0.9表。

军方关注任务，实业家关注取得机会，乡村民众承担扩张负担；地主/实业家对接纳计入治理负担。平等主义、人权阶段主要改变权利/专业相关集团的论证，而非全集团同一天相同道德转向。虔信者的分数由实际宗教机会和宗教办学条款争取，不受统一殖民奖励。医疗/军事科技不计作人文阶段。

0.9的七类分配条款共用每法案两槽，真实支付准备费和行政预留，取得和接纳分别讨论；殖民法律不批量批准州，不自动赋予居民权益或改宗。学校/医疗合同须实际机构增长及精确州正式整合，市场机会不代表已盈利。

原版战争与外交继续可用，无统一厌战惩罚或战争回调加罚。永久征募模块在已批准国家扩张计划、扩张原则和进攻方战争领袖共同满足时，按合法性相对调整潜在征兵量；不是逐战争目标授权，不替代原版动员，也不将一州批准扩展为其他州的接纳。和平继续核算债务、机构和旧合同。

205项离线测试通过，1.13本体未提供。机构、宗教比例、市场比较、法律、战争角色和真实存档接口须按 [TESTING.md](TESTING.md) 验收。0.6统一效果历史见 [LEGACY_0_6_COLONIAL_RULES.md](LEGACY_0_6_COLONIAL_RULES.md)。
