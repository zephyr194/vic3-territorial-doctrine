# 离线验证记录与 Vic3 1.13 验收

## 云端可复现检查

仓库根目录，Python 3.10+：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

当前96项测试通过。覆盖共同10%基础率、理由与体制修正、集团政治力量、最终通过率、全部32种五轮结果、资格/冷却、逐州审批隔离、转手后重新审批、失地宣称与家园保留、成本取整、整合条件边界、承诺履约、11个语言目录的键一致性、英文回退、打包和安装。

另对实际脚本做500组概率、500组常规/快轨成本数值对照，遍历理由/目标体制的新增恶名及接纳/放弃不加恶名。符号执行实际事件和效果文件，验证90天首轮、一次收费、12个合格月、暂停/回退/失地清理、单州状态写入、旧项目计时隔离、旧菜单不能改变活跃目标、只移除所选区域宣称。

新增覆盖默认关闭、只启用一次、关闭时旧事件隔离；72个集团政策profile与法律立场、保留原版意识形态、所有政策/阶段实际集团分数及成本；多重点独立等待、区域上限与预算、撤回后旧计时无效；逐目标战争授权、两个战争独立计数、20点上限、战中补办不能清除记录、负责国家不能被后来领袖覆盖、启用前战争豁免；已有宣称不新增恶名、接纳通过仍锁定直到付费项目。

符号执行器显式提供政治、人口、资格及作用域夹具，不模拟游戏引擎。战争目标集合由测试显式提供，并没有实现1.13目标查询；州所有者更新等部分效果也使用夹具。30天月份只用于分支测试。结构、引用、本地化、元数据、生成一致性检查通过；这些不能证明引擎兼容或游戏平衡。

可选社区符号检查：

```bash
git clone https://github.com/cwtools/cwtools-vic3-config.git /tmp/td-vic3-schema
python3 tools/validate.py --schema /tmp/td-vic3-schema
```

该检查验证符号存在，未执行完整CWT类型/作用域验证。开发时可用CWTools或Paradox Language Support加载实际1.13游戏路径。`--game-dir` 可核对本机原版数据库名称。

新增5项法律回归测试核对四组实际原生修正的得失与数值边界、集团受益方向、描述对每个实际效果的准确呈现、72个profile的当前立场文本，以及关闭时撤销旧法律且保留原版法律。已有启用测试也覆盖了清理后启用现状主义。
