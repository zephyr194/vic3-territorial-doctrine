# 离线验证与 Vic3 1.13 验收

## 云端可复现检查

Python 3.10+，仓库根目录：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

当前139项测试通过，包括共同10%基础率、理由与体制修正、全部32种五轮结果、政治力量、资格/冷却、重点区域预算/成熟/撤回、逐目标战争授权、两场战争独立上限、宣称与放弃、成本、承诺、11个语言目录及打包安装。

实际原生数值文件还有500组概率和500组项目成本对照。四条法律的原生集团/国家修正，以及新领土的产业/当地政治修正逐项核对游戏文本；72个政策profile的文字与实际支持立场一致。州开发效果验证启用时原有州（包括非文化家园）不享有加成、同区域的不同部分州隔离、新领土整合后仍符合资格、原有领土收复仍被排除、替换旧原则而不累计，以及排除条约港与外国军事占领。

新增接纳回归覆盖葡萄牙拥有广东西部、中国拥有同一区域另一部分、第三块葡萄牙州的隔离：批准、项目和完成都只作用于被审核的州。0%接受和高动乱不延长批准期限；在365日前不得完成，365日后完成；不足预算保留批准；失去主权取消；存读后原期限保持；旧菜单、旧法案轮次、旧项目计时不能改写新目标；再次启动不重复收费。

新增成果与当地政治测试覆盖实际授权取得、无授权/宣称失效不发奖、36个月不叠加或续期、失去获奖州撤销但保留锁定、取得反应不重复、接纳理由2%/3%和目标隔离、接纳完成周年才发放合法性、关闭状态不运行。人口变化测试核对原生效果的目标与比例，不模拟真实人口生成和转化。

0.6.1新增15项计划回归：葡萄牙/法国/日本的实际候选筛选，葡萄牙通过两份通用宣称后获得授权；殖民政策切换、医疗/军事科技排除；殖民逐州入口不批量接纳；空目标与旧菜单；防御调用和退出参战保护；追加目标、审议中/宣称失效；JSON恢复profile、法案事件队列、一年整合与每战计数。JSON恢复仅验证测试运行状态，不模拟游戏存档格式或引擎随机数。ZIP同时包含全部规则和验收说明。

符号执行器使用显式政治、人口与战争目标夹具，不是游戏引擎。州所有者历史更新等部分效果采用夹具，开发修正和接纳/计时分支实际执行。测试中的一个月=30天、一年=365天；原生完成事件使用 `years = 1`，实际游戏日历和回调顺序仍须验收。

可选社区符号检查：

```bash
git clone https://github.com/cwtools/cwtools-vic3-config.git /tmp/td-vic3-schema
python3 tools/validate.py --schema /tmp/td-vic3-schema
```

该检查验证符号存在，没有执行完整CWT类型/作用域验证。本机可以传入1.13本体路径：

```bash
python3 tools/validate.py --game-dir "/你的Steam路径/Victoria 3/game"
```

此检查还核对新增产业建筑/建筑组名称，不下载游戏或要求Steam凭据。社区配置中的产业名称不是1.13本体兼容的替代证明。
