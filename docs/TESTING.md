# 离线验证记录与 Vic3 1.13 验收

## 云端可复现检查

仓库根目录，Python 3.10+：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

当前58项测试通过。覆盖共同10%基础率、理由与体制修正、集团政治力量、最终通过率、全部32种五轮结果、资格/冷却、逐州审批隔离、转手后重新审批、失地宣称与家园保留、成本取整、整合条件边界、承诺履约、双语键一致性、打包和安装。

另对实际脚本做500组概率、500组常规/快轨成本数值对照，遍历理由/目标体制的新增恶名及接纳/放弃不加恶名。符号执行实际事件和效果文件，验证90天首轮、一次收费、12个合格月、暂停/回退/失地清理、单州状态写入、旧项目计时隔离、旧菜单不能改变活跃目标、只移除所选区域宣称。

符号执行器显式提供政治、人口、资格及作用域夹具，不模拟游戏引擎。30天月份只用于分支测试。结构、引用、本地化、元数据、生成一致性检查通过；这些不能证明引擎兼容或游戏平衡。

可选社区符号检查：

```bash
git clone https://github.com/cwtools/cwtools-vic3-config.git /tmp/td-vic3-schema
python3 tools/validate.py --schema /tmp/td-vic3-schema
```

该检查验证符号存在，未执行完整CWT类型/作用域验证。开发时可用CWTools或Paradox Language Support加载实际1.13游戏路径。`--game-dir` 可核对本机原版数据库名称。

## 游戏内必须执行（均未运行）

记录1.13具体补丁号；使用新测试档、仅本模组的播放集及 `-debug_mode`。分别以西班牙、清朝和另一民主国家测试。在本次启动的用户数据 `logs/error.log` 搜索 `td_`、`lawgroup_territorial_doctrine`、`td.` 与文件名，保留完整触发步骤。

| 检查 | 预期 |
|---|---|
| 中英切换 | 法律、决议、日志、理由菜单和提示均有对应语言，目标名/数字正确 |
| 初始化/改法 | 默认现状；八集团倾向正确；改法锁定5年；未重复添加意识形态 |
| 同基础率 | 固定集团/合法性/人口输入，各政府权力组合无理由修正时同为10%基础项 |
| 理由门槛 | 非邻接不能选安全，无法理不能选法理，行政接管只接纳，和平解决只放弃 |
| 修正 | 君主＋独裁安全+7，共和＋民主平等+8；改政体只改变理由修正，不换基础项 |
| 原版外交 | 原版博弈、战争目标、恶名保留；法案不直接取得领土；原版没有新增理由菜单 |
| 宣称代价 | 同理由/法律对独裁与民主目标分别套0.9/1.25额外恶名倍率，不重复支付 |
| 北非示例 | 利益要求、法律行政/权威预留、6/12月等待有效；历史法律不虚构权利 |
| 法案计时 | 90天首轮；3成/3败停止；查看不抽签；取消/改法/失效冷却2年 |
| 两州接纳隔离 | 准備两个拥有的未整合非家园州：批准A只解锁A，B仍不能直接整合 |
| 部分州/条约港/占领 | 本国部分州可处理；条约港与纯军事占领不可处理；主体文化家园不需处理 |
| 转手与复得 | 旧接纳移除；新所有者和原所有者复得后分别重新审批；不继承旧整合 |
| 州创建回调 | 开局已整合州不降级；运行中新取得的非家园州降为未整合并加审批限制 |
| 旧菜单 | 提交另一法案或开始项目后，旧浏览/理由窗口不能改写活跃目标 |
| 逐区放弃 | 清朝完全丢失一个有宣称/家园依据的区域后，审批只移除该区域真实宣称 |
| 放弃限制 | 仍拥有该区域部分州或已放弃则不能再次放弃；家园/所有权/其他宣称不变 |
| 无真实宣称的失地 | 有家园依据仍可登记放弃；没有创造新宣称；模组不自动恢复已放弃主张 |
| 原统治体制缓存 | 独裁/民主前所有者的转手成本不同；前所有者灭亡后保留记录；未知记录中性回退 |
| 当地成本 | 动乱/战损/未充分接受比例提高行政预留；开启项目后成本按快照固定 |
| 人口计算 | 按实际人数累加充分接受且宗教未歧视的POP；不按POP条目数量或文化均值计算 |
| 快轨与回退 | 12个合格月只整合项目州；连续6个不足月转常规；恢复重置连续不足计数 |
| 常规与清理 | 原版州界面手动整合；完成/失地后释放预留；原版AI能否自行开启需要实测 |
| 旧计时 | A失地后开启B项目，A遗留的月度事件不能推进或完成B |
| 承诺 | 两项各给对应集团+10；完整取得阿尔里夫后登记基线/3年期限；失地复得不重置 |
| 存读档 | 法案第2轮、快轨第6月、原所有者灭亡后、承诺期限内分别重载，状态与剩余计时保留 |
| 1.13数据库 | 验证州/区域/法律/建筑/接受等级标识及所有作用域、回调和动态本地化取值 |

此版本要求新测试档，未做0.2国家级接纳向0.3逐州记录的迁移。云端无游戏本体，以上引擎项目均未运行；通用新增宣称与扩张AI也尚未实现。
