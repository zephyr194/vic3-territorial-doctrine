# 0.7.0-alpha.1：离线验证与 Vic3 1.13 验收

## 云端可复现检查

Python 3.10+，仓库根目录运行，无第三方Python依赖：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

当前157项离线测试，其中32项为新谈判与合同回归。测试读取实际生成的法案、效果、数值和本地化文件。`tests/native_runner.py`为这些脚本提供明确的原版数据夹具和受限效果执行器，不能代替游戏引擎。JSON往返检查脚本变量的持久性，不等于真实Vic3存档或随机数状态验证。

### 覆盖范围

| 范围 | 检查内容 |
|---|---|
| 逐轮谈判 | 手动继续、付费签约、查看账目、撤回、重开；旧法案窗口、旧轮次窗口、重复延迟计时不能扣款或操作新轮次；目标失效取消；AI自动选择可负担条款并继续 |
| 真实成本 | 国库实际减额、最低勘察费、10行政预留、重复签约阻止、第二合同预算检查、铁路科技与海军基地沿海资格；没有免费建筑 |
| 支持分 | 实际执行政治脚本，读取原版认可与政治力量夹具、领袖立场、实际权利法律、付费与违约分项；支持变化不改政治力量 |
| 合同对象 | 已拥有的实际州与签约基线；外国州区域取得后绑定实际州；拒绝用已有本国部分兑现新外国合同；其他州建设不兑现 |
| 履约追责 | 三年交付、五年未取得中性到期、失地复得与改法不刷新期限；兑现/违约只反馈相关集团，不叠加同名修正；迟建不撤销旧违约；取消新法案保留旧批准合同 |
| 独立状态 | 法案、年度项目、合同各有冻结目标；事件通知保存目标；一个已付费接纳项目不冻结另一州讨论；存读保留已支付金额、期限、基线、目标与批准状态 |
| 逐州接纳 | 同州区域的葡萄牙/中国部分州隔离；只有被批准且拥有的非家园普通州可接纳；一年周年之前不完成，周年后完成；预算不足保留批准，失地主权取消；低接受度与高动乱不延长已付款期限 |
| 政策与数值 | 殖民政策切换、两项人文科技阶段、各政体同一基础率、宣称/接纳/放弃目标、失败冷却、500组概率与500组项目成本对照 |

部分离线模型仍含资源、同胞等设计输入，作为方案夹具，不代表原生代码已读取这些事实。新32项谈判测试执行实际政治与合同脚本；读取人口、建筑和集团时使用显式引擎数据夹具。为已退役的旧属性包改为验证其不存在及兼容清理；不以旧加成测试结果证明新方案。

## 社区符号与本体标识检查

```bash
python3 tools/validate.py --schema /path/to/cwtools-vic3-config
python3 tools/validate.py --game-dir '/path/to/Victoria 3/game'
```

社区CWT仅检查脚本符号覆盖，**不检查完整作用域、参数类型、列表枚举或1.13运行行为**。`--game-dir`只核对所需原版标识存在；不会启动游戏。当前云端没有1.13本体，数据库与游戏运行结果均为UNRUN。

## 必须完成的1.13游戏内验收

使用新测试档，启用调试日志，并只启用本模组；不要把旧alpha档当成已迁移存档。记录实际版本、国家、目标、选项、时间和日志，逐项确认：

1. 默认关闭，启用决议显示并能激活；国家领土原则、集团偏好和双语描述正常，其他语言显示英语回退。低合法性可讨论，破产/内战/主权资格符合流程。
2. 在不同国家提出相邻、区域利益、历史宣称与殖民目标；拒绝无实际资格目标，不依赖额外重点区域成熟。确保区域、相邻、领袖、殖民与权利法律标识在1.13有效。
3. 人类每90天看到谈判窗口及冻结州名；选择“继续”才结算该轮；关闭可重开。确认引擎窗口超时默认选项不会自动付费；AI继续，无人类弹窗。真实S/O、概率及八集团账目一致。
4. 签合同前后比对实际国库黄金与行政余额；确认`add_treasury`、`gold_reserves`和规划修正作用域，手续费只扣一次。破产、零人口、少储备、内陆海军基地、未研究铁路、条约港均不能错误签约。
5. 已有州记录实际建筑基线；其他州增加设施不算兑现，绑定州净新增一级才兑现。拆除后重建到原基线不算新增。确认1.13的`state_has_building_type_levels`是否按预期只读绑定州。
6. 外国合同取得目标区域普通州时绑定实际州，排除原已拥有部分和条约港；分割、转手、州对象销毁与复得均不可拿其他州刷兑现，期限不得刷新。对象销毁后的处理尤其需要本体确认，离线夹具不能证明重建后的州身份。
7. 三年到期未兑现使相关集团认可−5、信用−10五年；按时兑现认可+2三年。相同修正不叠加；真实到期消退。五年未取得释放规划预留，不追加建筑违约。
8. 葡萄牙拥有广东西部、另一国拥有同一区域其余部分时：逐实际州通过接纳、付款、满一年整合；不批准另一州。已付款项目不阻止另一个法案，但第二年度项目等待槽位。文化、宗教和接受等级继续原版变化。
9. 分别在谈判前、签约后、批准后、取得后、接纳项目中保存/读取真实游戏存档；冻结目标、勘察扣款、规划预留、期限与基线不变。旧事件不能操作新法案或新项目。
10. 原版主动战争、收复、防御和多目标战争仍运行；不额外扣厌战或用国内手续禁止战争。法案批准只是国内政治结果与宣称，不直接转移主权。确认旧效果没有残留在新档。

税制、征兵、公共服务条款、详细资源/市场回报与完整意识形态响应尚未实现；不用上述验收结果宣称它们已经可用。参数的方向、付出和退出条件见 [DESIGN.md](DESIGN.md)，数值属于待校准的游戏抽象。
