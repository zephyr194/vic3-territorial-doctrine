# 验证记录与 Vic3 1.13 验收

## 云端可复现检查

在仓库根目录、Python 3.10+：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

测试覆盖政治分阈值、历史/资源/同胞资格、50%示例、最终通过率、所有32种5轮结果、取消与冷却、整合条件边界、成本取整和承诺履约。

当前云端记录：42项测试通过；生成文件一致性、结构/引用/本地化检查、上述社区CWT符号检查、参照场景以及ZIP/安装工具检查通过。实际1.13引擎加载和游戏内验收未运行。

对实际脚本另有500组数值对照，以及90天计时、通过后宣称与接纳分离、延迟取消事件、失败承诺清理、12次月度检查、暂停恢复、回退及失地主动清理的符号执行。符号执行器显式提供资格与政治输入，不模拟游戏人口或作用域，也不证明游戏引擎会按同样方式执行。其月计时用30天，只用于测试分支，不代表游戏日历月份长度。

可选社区接口符号检查：

```bash
git clone https://github.com/cwtools/cwtools-vic3-config.git /tmp/td-vic3-schema
python3 tools/validate.py --schema /tmp/td-vic3-schema
```

这个检查只验证符号存在，不是完整的CWT类型/作用域验证。开发时可用CWTools或Paradox Language Support加载1.13实际游戏路径进行更强检查。

## 游戏内必须执行（目前未运行）

先记录游戏菜单版本号1.13及具体补丁号。在启动器给测试播放集设置 `-debug_mode`，使用新档西班牙。游戏用户数据 `logs/error.log` 中搜 `td_`、`lawgroup_territorial_doctrine`、`td.` 和相应文件名；保留本次启动日志，避免把旧日志当成当前结果。

| 检查 | 预期 |
|---|---|
| 新档初始化 | 法律组出现、默认现状主义，未增加锁定或重复意识形态 |
| 改法 | 八集团显示对应倾向；原版立法完成后5年锁定 |
| 北非重点区域 | 50行政/25权威等法律成本真实减少，等待期未结束不能宣称 |
| 历史法律 | 西班牙不能利用北非重点区域虚构阿尔里夫历史权利 |
| 宣称 | 90天第一次结算；3成或3败后停止，无多次恶名扣算；不转移土地 |
| 支持视图 | 动态值正确，点击查看不产生新轮次或抽签 |
| 承诺 | 不改变全国概率常数；集团分数+10，最多2项；同集团旧义务未结束不可重复 |
| 取消/改法/失效 | 2年冷却；旧延迟事件不重启；已通过承诺仍在 |
| 完整主权 | 开局西班牙部分持有或战时占领不能提出接纳；取得整个州区域后可以 |
| 承诺计时 | 完整取得主权后登记建筑基线，3年内净增1级兑现；失地/复得不重置期限 |
| 接纳 | 另一次3成/3败流程；不修改文化、宗教、家园或实际接受等级 |
| 快轨正例 | 准备满足全部条件的测试存档：12个合格月后正式州，成本释放 |
| 快轨负例 | 每次只破坏一个条件，不计有效月；恢复后继续；连续6个不合格月转常规 |
| 常规路线 | 原版州界面手动开始，原版时长；完成或失地后月度释放项目成本 |
| 存档重载 | 在法案第2轮、快轨第6月、承诺期限内分别存读档，计数/目标/剩余计时不重置 |
| 版本标识 | `STATE_AL_RIF`、`region_north_africa`、`country_bankruptcy`、建筑名称及接受等级在1.13中存在 |

首版只实现固定场景；不要用上述结果宣称多国多州、其他处置或扩张AI通过测试。若接口错误，保存具体版本、触发步骤与本次 `error.log`，再按1.13实际脚本调整。云端没有游戏本体，所以当前这些项目均为未运行。
