# 安装 alpha 测试版（目标 Vic3 1.13）

尚未在游戏内验收。请使用独立测试存档与仅包含本模组的测试播放集。

## ZIP 安装

解压 `territorial_doctrine-0.3.0-alpha.1.zip`，将 `territorial_doctrine/` 和 `territorial_doctrine.mod` 放进用户数据目录下的 `Victoria 3/mod/`。不是 Steam 的游戏安装目录。常见位置：

- Windows：`文档/Paradox Interactive/Victoria 3/mod/`（文档可能由 OneDrive 重定向）。
- Linux：`~/.local/share/Paradox Interactive/Victoria 3/mod/`。
- macOS：`~/Documents/Paradox Interactive/Victoria 3/mod/`。

在 Paradox 启动器添加本地模组并加入播放集。若启动器不接受 ZIP 中的相对路径，使用启动器“创建模组”生成本地路径记录，再将载荷目录内容复制进去，或采用下方安装脚本写入绝对路径。

## 从源码安装

本地安装 Python 3.10+，在仓库根目录运行：

```bash
python tools/package.py --install-dir "/你的用户数据路径/Paradox Interactive/Victoria 3/mod"
```

该命令只创建本模组目录和对应 `.mod` 文件。若同名安装已存在会拒绝覆盖，请自行备份并移走旧版本后再装。它不会登录 Steam、下载游戏或改变原版游戏文件。

加载前，可对本机1.13数据库做标识检查（路径末尾是 `game`）：

```bash
python tools/validate.py --game-dir "/你的Steam游戏路径/Victoria 3/game"
```

这只核对用到的数据库名称。引擎作用域和运行行为还需要按 TESTING.md 验收。不要把只运行上述工具当作已通过游戏兼容测试。

## 首次玩法

使用新档，游戏语言切换为简体中文或英文即可获得对应界面。

接纳已有领土（任意主权国家）：

1. 选择“处理一块非文化家园州”决议。
2. 按人口排序浏览候选州，选择理由，核对体制修正和预计成本后提交。没有选择理由不会开始审议。
3. 每90天结算；3次成功后仅该州解锁整合。其余州仍须分别立法。
4. 选择“选择已接纳的一州整合”，开始常规或满足条件后的一年快轨。常规仍需在原版州界面启动。

放弃失地宣称（任意主权国家）：

1. 先在原版流程中失去某个州区域全部主权，例如清朝失去外东北。
2. 选择“放弃一块失地的领土宣称”，浏览具备宣称或主体文化家园依据的州区域。
3. 选择和平解决理由并提交。通过仅移除选中区域的宣称并记录放弃，家园与当前所有权不变。多个失地区域逐一处理。

新增宣称示例：西班牙改为战略边疆/帝国扩张，建立原版北非区域利益，指定重点并等待6/12月。提出阿尔里夫法案，选理由后提交，可另作两项建设承诺。通过后使用原版外交取得主权，再按上述流程处理拥有的非家园州。历史权利主义不会凭北非重点授予虚构权利；承诺仍以完整取得阿尔里夫州区域为计时条件。

战时占领不是主权；条约港不参与接纳。开局已整合州不追溯审批，新增非家园州不能继承前所有者的审批。0.2版国家级接纳记录不迁移为逐州记录，不建议使用旧测试档。前统治者无可靠记录时行政倍率回退为中性1.0。
