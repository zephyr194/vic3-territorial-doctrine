# 安装与启用（目标 Vic3 1.13）

版本 `0.6.1-alpha.1`，尚未在游戏内验收。使用新测试存档、仅本模组的播放集。

## 安装ZIP

ZIP内同时包含完整规则、计划交付说明与验收清单。解压 `territorial_doctrine-0.6.1-alpha.1.zip`，将 `territorial_doctrine/` 和 `territorial_doctrine.mod` 放入用户数据目录的 `Victoria 3/mod/`：

- Windows：`文档/Paradox Interactive/Victoria 3/mod/`，文档可能由OneDrive重定向。
- Linux：`~/.local/share/Paradox Interactive/Victoria 3/mod/`。
- macOS：`~/Documents/Paradox Interactive/Victoria 3/mod/`。

在Paradox启动器添加本地模组并加入播放集。若相对路径未被识别，用启动器“创建模组”生成本地路径记录后复制载荷，或使用下方安装脚本写入绝对路径。

## 从源码安装

Python 3.10+，仓库根目录：

```bash
python tools/package.py --install-dir "/你的用户数据路径/Paradox Interactive/Victoria 3/mod"
```

同名安装已存在时拒绝覆盖；请先备份并移走旧版。此脚本只安装模组，不登录Steam或修改原版文件。GitHub Actions的验证任务也会保存安装ZIP构件。

可以检查本机1.13数据库名称，路径末尾应为 `game`：

```bash
python tools/validate.py --game-dir "/你的Steam游戏路径/Victoria 3/game"
```

数据库名称检查不能替代引擎验收，具体清单见 [TESTING.md](TESTING.md)。

## 先确认已加载，再启用

1. 开新测试档，打开决议菜单。
2. 出现“启用国家领土原则”与“国家领土原则模组状态”，即说明模组载荷已加载。状态决议可查看当前关闭/启用状态。
3. 点击“启用国家领土原则”，才开启本存档所有国家的法律组、逐州接纳限制、殖民政治与战争授权。AI不能执行此启用决议。
4. 默认领土现状主义；启用后不提供关闭决议。已经开始的战争不追溯惩罚。

状态决议在启用后仍保留。存档中的标记可能在卸载后残留，因此应以决议实际出现作为加载判断，不能只检查旧存档变量。

语言随游戏设置：英文与简体中文有对应翻译，其他9个语言目录回退为英语。不强制改变玩家的游戏语言。

## 宣称与重点区域

改为历史权利、战略边疆或帝国扩张后，选择通用领土宣称决议，逐个浏览合格的外国目标并选择理由。历史权利只承认已有真实宣称或主体文化家园；战略边疆允许相邻州，也允许重点区域内符合殖民或西班牙示例安全依据的目标；帝国扩张可选择已建立原版利益的外国区域。

远方目标在理由菜单中指定所属战略区域为重点，预留行政/权威，等待6个月（历史/边疆）或12个月（帝国）成熟。成熟前无法提交需要该重点的法案。撤回重点或改法会使旧等待事件失效。相邻边疆、合格历史主张不强制等待重点。

选好理由后核对修正、额外恶名与预计行政成本，提交审议。每90天一轮，3成通过、3败否决；失败或撤回冷却2年。通过增加真实宣称和该区域的授权记录，随后按原版外交取得主权。已有原版宣称也需经过法案才能获得本模组战争授权，但不收取新宣称额外恶名。目标不再存在或候选为空时显示“暂无合格领土目标”，不会提交空法案；重新检查原则和原版区域利益后再选择。

## 独立接纳修正案与一年整合

1. 点击“提出一州领土接纳修正案”，浏览本国拥有、未整合、非条约港的非文化家园州。
2. 为选定州选择理由，复核以该州命名的修正案与年度行政成本，提交政治审核。日志显示《目标州领土接纳修正案》，每90天一轮，3成通过、3败否决。
3. 通过只为该州记录当前国家与理由，并添加“本州接纳修正案已批准”，该州一次性减少激进派、增加效忠派，各按人口2%计算，平等理由为3%，受原版人数上限约束。行政力足够时立即开始该州的一年整合；不足时批准保留，使用“为一个已批准州启动一年整合”决议支付成本后再开始。
4. 查看《目标州接纳修正案》一年整合日志。一个日历年后自动成为正式州，无需再点击原版整合按钮；其他州仍受独立审核限制。

葡萄牙案例：取得广东西部的普通领土主权后，提交《广东西部领土接纳修正案》。这份批准只涉及葡萄牙拥有的部分州；即使中国的另一部分共享同一州区域，也不会一并批准或整合。若指开局澳门条约港，则先通过原版流程取得普通领土主权。

不要求居民先被文化接受，0%接受仍可走这条法律路线。动乱、战损、人口、殖民政策和原统治体制影响政治支持或成本，已付款项目不会因此延长批准期限。后来行政赤字也不重置已批准的年度期限，国家仍持续承担预留成本。丢失主权则取消原所有者的批准与项目；新所有者须重新审核。

原版文化、宗教、家园与接受等级保留。军事占领不等于主权，部分州按本国实际拥有范围处理。开局已整合州不追溯降级，之后非家园新取得州须重新审批。

## 法律增益

法律界面显示集团、国家与新领土持续效果；不再给予固定合法性。现状偏民生产业，历史偏农林业，边疆偏军工和基础工业，帝国的指定12类军工供应链各+10%吞吐量，包含煤铁铅硫、钢铁、工具、化工、动力机械、武器、弹药、战争机器和造船。吞吐量会增加投入需求与产出，并非免费产出。

启用时登记所有原有州，包含非文化家园州；仅之后新取得的普通州获得产业吞吐量、建设效率、移民吸引力和持续当地政治修正。原有州丢失再收复仍不享有开发加成；同一地图州区域中的不同部分州分别判断，成为正式州后新领土仍保留资格。外国军事占领地不获得本国建设权，条约港不进入此开发流程。原版迁移法律继续适用。实际取得已批准且宣称有效的目标后，历史/边疆/帝国可获+6/+8/+12合法性；完成接纳整合可获+3。共用36个月、不叠加或续期，失去获奖州提前移除而保留锁定期。宣称通过与宣战不发放合法性。当地政治效果区分取得时一次性反应与歧视/生活水平变化的生成倍率。具体数值与恶名、合法性取舍见 [DESIGN.md](DESIGN.md)。

## 放弃与战争

清朝等国家完全失去某一有宣称或主体文化家园依据的州区域后，可逐区选择和平解决法案。通过仅移除该区域本国宣称并登记放弃，不改变文化家园或当前所有权。

主动征服/吞并前需要战略边疆或帝国扩张原则，以及每个目标区域通过的法案和仍有效的真实宣称。吞并整个国家需逐区授权。缺少任一条件，开战时的进攻方战争领袖每月额外+2厌战度，每场最多20；战中补办不能抹掉未授权开战记录。防御方、纯归还领土、非领土战争豁免。首次快照只允许进攻方建立；负责国家退出战争后停止追加厌战，存读不重置已累计数。完整殖民/科技/战争规则见 [COLONIAL_WAR_RULES.md](COLONIAL_WAR_RULES.md)。

0.6在启用时登记原有领土，沿用一年日历计时与独立法案序号；旧alpha存档不是受支持的迁移路径，请开新测试档。关闭状态会清理旧项目/意识形态等运行记录，但不会还原旧版已造成的宣称、整合、文化或主权变化。前统治者历史未知时使用中性成本，不猜测来源。
