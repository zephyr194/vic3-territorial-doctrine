# 国家领土原则 · Territorial Doctrine

[English](docs/README.en.md)

面向《维多利亚3》**1.13** 的领土立法模组，版本 **0.4.0-alpha.1**。增加四条国家领土原则，以及逐目标宣称、逐州接纳、逐区放弃失地宣称。

**加载后默认关闭。** 在决议中点击“启用国家领土原则”，才为本存档所有国家开启法律组、接纳限制、殖民政治和战争授权规则。启用决议与始终可见的“国家领土原则模组状态”决议可用于确认模组已加载；AI不能启用。测试版启用后不提供关闭入口，建议使用新测试存档。

| 功能 | 当前行为 |
|---|---|
| 语言 | 随游戏设置；英文与简体中文有翻译，其余9个语言目录使用英文回退 |
| 共同基础率 | 所有政府、权力体制共用10%；七种理由决定体制修正 |
| 宣称 | 各国可浏览合格目标；远方扩张需要原版区域利益与已成熟重点区域 |
| 接纳 | 每次处理一州；通过后还需支付该州整合项目成本，才解锁整合 |
| 放弃宣称 | 每次处理一个完全丢失的州区域；保留文化家园与当前主权 |
| 殖民政治 | 迁居/剥削政策影响法律与集团倾向；平等主义、人权科技降低扩张倾向、提高接纳倾向 |
| 居民权利成本 | 殖民政策及人文阶段增加行政项目预留，政治支持提高不等于整合免费 |
| 战争授权 | 主动征服/吞并需要扩张原则和所有目标的法案授权；缺少任一项每月额外+2厌战度，每场上限20 |
| 豁免 | 防御方、纯归还领土或非领土战争；启用前已开始的战争不追溯 |
| 原版外交 | 保留博弈、战争目标和原版恶名；法案不直接取得主权 |
| AI | 开启后按同一规则提出宣称、接纳及预算允许的常规整合项目 |

**云端已通过91项离线测试，尚未在 Vic3 1.13 引擎加载或游玩。** 资源短缺、同胞人口门槛、历史登记、列强风险仍有未接入的设计项；通用建设承诺仍只保留西班牙—阿尔里夫示例。详细边界见 [设计说明](docs/DESIGN.md)。

开发仅需 Python 3.10+，无第三方依赖：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

安装包：`dist/territorial_doctrine-0.4.0-alpha.1.zip`。GitHub Actions验证通过后也保存ZIP构件。见 [安装说明](docs/INSTALL.md) 与 [游戏验收清单](docs/TESTING.md)。

`mod/` 是游戏载荷，`territorial_doctrine/rules.json` 是共享规则源。生成器维护法律、集团意识形态、政策数值、常量、修正、图标、本地化目录和元数据，其余原生脚本直接维护。修改规则后重新生成并检查。云端无需Steam凭据或下载游戏，本地1.13本体用于引擎验收。
