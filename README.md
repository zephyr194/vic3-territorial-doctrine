# 国家领土原则 · Territorial Doctrine

[English](docs/README.en.md)

《维多利亚3》**1.13** 目标版本的领土立法模组，当前为 `0.3.0-alpha.1`，支持简体中文与英文。增加四条国家领土原则法律，以及制造宣称、逐州接纳、放弃失地宣称三种领土法案。

各国共用10%基础通过率，所选理由与政府、权力体制的匹配产生加减分。非主体文化家园的未整合州需要逐州审批：通过只解锁该州，转手后重新审批。可针对已经完全丢失的州区域放弃宣称，例如清朝失去外东北后逐区承认边界。原版外交博弈、战争目标与恶名保留；模组新增宣称的额外恶名和行政整合成本随体制、理由及当地状况变化。

**云端只完成离线验证，尚未在 Vic3 1.13 本体加载或游玩。** 接纳、放弃宣称适用于各国；新增宣称和建设承诺目前仍只开放西班牙—阿尔里夫示例。

开发需要 Python 3.10+，无第三方依赖：

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

安装包为 `dist/territorial_doctrine-0.3.0-alpha.1.zip`。见 [安装说明](docs/INSTALL.md)、[规则与实现范围](docs/DESIGN.md)、[游戏验收清单](docs/TESTING.md)。使用新测试存档；0.2版国家级接纳记录不迁移为0.3版逐州记录。

| 内容 | 当前实现 |
|---|---|
| 四条法律、八集团倾向、5年改法锁定 | 沿用原版改法流程 |
| 理由与体制 | 五种理由；共同基础率；理由可用性和体制加减分 |
| 已有非文化家园地区 | 全国家逐州选择、审批；未批准州禁止直接整合 |
| 新取得的地区 | 非家园、非条约港州重新审批，不继承前所有者的接纳 |
| 放弃失地宣称 | 逐个完全丢失的州区域；移除宣称并记录放弃，不改变家园 |
| 计时 | 每90天一轮，3成/3败；失败或取消冷却2年 |
| 代价 | 目标体制影响新增宣称恶名；本国/原统治体制及当地状况影响行政预留 |
| 整合 | 单项目；原版常规路线或12个合格月快轨；连续6个不合格月回退 |
| AI | 自动逐州提出行政接纳，预算足够时进入常规路线；扩张AI未开放 |
| 新增宣称、重点区域、承诺 | 西班牙—阿尔里夫示例：北非重点、海军基地与铁路承诺 |
| 通用新增宣称选择、资源记录、列强风险、自治/殖民路线 | 尚未接入游戏；部分资格仅有离线模型 |

`mod/` 为游戏载荷。法律、意识形态、基础分、常量、体制数值、修正、法律文本、图标和元数据由 `tools/generate.py` 从 `territorial_doctrine/rules.json` 生成；其余脚本直接维护。修改规则后运行生成器和检查。

云端直接使用现有仓库，无需 Steam 凭据或下载游戏。1.13本体用于本地引擎验收。
