# 国家领土原则 · Territorial Doctrine

[English](docs/README.en.md)

《维多利亚3》**1.13**，版本 **0.9.0-alpha.1**。本版实现八集团的付费利益分配：七类承诺共用两槽，殖民响应按集团区分，逐目标协商扩张、接纳与放弃主张。

从GitHub克隆后快速安装（Python 3.10+，无第三方依赖）：

```bash
git clone https://github.com/zephyr194/vic3-territorial-doctrine.git
cd vic3-territorial-doctrine
python vtd.py install
```

Windows也可双击根目录的`vtd.cmd`打开安装菜单；Linux/macOS使用`python3`或`./vtd.sh`。`python vtd.py update`同步当前本地源码，`remove`移除，`status`查看路径和安装状态。自动识别用户数据的mod目录，特殊路径用`--mod-dir "路径"`指定。更新/移除前自动备份旧安装，存档和其他模组保留。远端更新先执行`git pull --ff-only`；改动共享规则后用`update --generate`重新生成并安装。详见 [安装工具说明](docs/INSTALL.md#源码安装工具)。

**加载后默认关闭。** 在决议中选择“启用国家领土原则”；启用与状态决议用于确认模组加载。英文与简体中文有翻译，其余9个语言目录完整回退英语，界面随游戏语言。

| 功能 | 当前行为 |
|---|---|
| 国内审议 | 固定一个目标；每90天谈判，可付费承诺、查看集团账目、继续或撤回；三成通过、三败否决 |
| 集团支持 | 原版政治力量与认可、部分领袖立场、理由、殖民倾向和实际付费承诺；各分项可见 |
| 分配合同 | 基地、铁路、宗教/公共教育、医疗、地主制度与低税保障；每法案最多两项，实际付费/预留行政 |
| 履约 | 按绑定州的建筑基线与三年期限复核；兑现/违约只给相关集团暂时认可和信用反馈 |
| 逐州接纳 | 独立修正案，批准与付款后一年行政整合；不改变文化、宗教、实际接受或人口政治状态 |
| 并行讨论 | 年度整合不冻结其他法案；当前支持一份审议、一项已付款整合、每类一份未履约合同 |
| 永久核算 | 三项独立决议，全存档启用后无关闭；实际税档、合法性征募及服务/行政负担 |
| 来源标记 | 所有模组自有提示、名称和修正文本以VTD开头，11种语言目录一致 |
| 原版结果 | 无固定产业、建设、移民、政治力量、合法性或人口奖励；无额外宣称恶名和战争厌战 |

勘察费用为`max(5000, ceil(目标人口×0.01))`，从黄金储备支付且不退还；建筑、就业与维护另由原版承担。铁路需研究铁路科技，海军基地需沿海。外国合同先绑定目标州区域，只有该区域原先没有本国部分时可早签，取得后再绑定实际本国州；已有部分州可通过其接纳法案签约。条约港不适用。

227项离线测试通过，包括22项安装工具、32项谈判/合同、22项核算及26项分配回归；**未完成1.13实机验证**。逐人口税额、自动借债、具体产权/利润/工资和完整意识形态响应尚未接入。参数是公开可调的游戏抽象，不是历史支持率。具体规则与边界见 [DESIGN.md](docs/DESIGN.md)。

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

Python 3.10+，无第三方依赖。安装包：`dist/territorial_doctrine-0.9.0-alpha.1.zip`，包含完整规则与验收文档。请使用新测试存档；旧alpha没有完整迁移。见 [安装](docs/INSTALL.md)、[验收](docs/TESTING.md)。源规则为`territorial_doctrine/rules.json`，生成器维护共享数据、图标与语言回退；其余原生脚本直接维护。


启用主系统后，可分别执行“VTD 永久启用领土财政核算／征募政治响应／公共服务责任核算”。财政提供真实税档升降与收支账目；征募须已批准扩张计划及主动战争，按合法性最多相对±10%；服务按实际机构削减和行政缺口进入集团谈判，不按扩张标签自动砍学校/医院。和平继续核算债务与服务恢复，原有合同仍须履行。具体公式和退出条件见DESIGN.md的0.8节。


0.9的新合同可从谈判窗口或决议选择。机构合同须实际增加原版机构投入且绑定州正式整合；土地保障只保持记录的土地法律，低税保障保持实际低税至少一年。机会分说明拟争取的市场/宗教空间，不宣称已经扩权、获利或改宗；具体数值与未评估范围见DESIGN.md的0.9节。
