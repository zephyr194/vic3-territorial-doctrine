# 国家领土原则 · Territorial Doctrine

[English](docs/README.en.md)

《维多利亚3》**1.13**，版本 **0.7.0-alpha.1**。本版实现扩张与接纳的国内谈判，替换旧原型的固定属性礼包与统一战争惩罚。

**加载后默认关闭。** 在决议中选择“启用国家领土原则”；启用与状态决议用于确认模组加载。英文与简体中文有翻译，其余9个语言目录完整回退英语，界面随游戏语言。

| 功能 | 当前行为 |
|---|---|
| 国内审议 | 固定一个目标；每90天谈判，可付费承诺、查看集团账目、继续或撤回；三成通过、三败否决 |
| 集团支持 | 原版政治力量与认可、部分领袖立场、理由、殖民倾向和实际付费承诺；各分项可见 |
| 通用合同 | 铁路/海军基地：实际支付勘察费并预留10行政力，不创建免费建筑 |
| 履约 | 按绑定州的建筑基线与三年期限复核；兑现/违约只给相关集团暂时认可和信用反馈 |
| 逐州接纳 | 独立修正案，批准与付款后一年行政整合；不改变文化、宗教、实际接受或人口政治状态 |
| 并行讨论 | 年度整合不冻结其他法案；当前支持一份审议、一项已付款整合、每类一份未履约合同 |
| 原版结果 | 无固定产业、建设、移民、政治力量、合法性或人口奖励；无额外宣称恶名和战争厌战 |

勘察费用为`max(5000, ceil(目标人口×0.01))`，从黄金储备支付且不退还；建筑、就业与维护另由原版承担。铁路需研究铁路科技，海军基地需沿海。外国合同先绑定目标州区域，只有该区域原先没有本国部分时可早签，取得后再绑定实际本国州；已有部分州可通过其接纳法案签约。条约港不适用。

157项离线测试通过，包括32项真实谈判/合同脚本回归；**未完成1.13实机验证**。税制、征兵、公共服务合同及详细资源/收益评估尚未接入。参数是公开可调的游戏抽象，不是历史支持率。具体规则与边界见 [DESIGN.md](docs/DESIGN.md)。

```bash
python3 tools/generate.py --check
python3 -m unittest discover -s tests -v
python3 tools/validate.py
python3 tools/scenario.py
python3 tools/package.py
```

Python 3.10+，无第三方依赖。安装包：`dist/territorial_doctrine-0.7.0-alpha.1.zip`，包含完整规则与验收文档。请使用新测试存档；旧alpha没有完整迁移。见 [安装](docs/INSTALL.md)、[验收](docs/TESTING.md)。源规则为`territorial_doctrine/rules.json`，生成器维护共享数据、图标与语言回退；其余原生脚本直接维护。
